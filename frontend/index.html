Got Questions?

Frequently Asked Questions

Everything you need to know about CogniStudy AI.

How does the AI Notes Generator work? ▼
The generator parses study text or lecture notes into structured sections: an Executive Overview, Key Core Concepts, Essential Terminology, and an Exam Memory Checklist. You can then use the built-in rich text editor and AI Tools (Shorten, Expand, Simplify) to tailor the output.
Can I generate flashcards and quizzes directly from my notes? ▼
Yes. From any generated note, click "Convert to Flashcards" or "Convert to Quiz" to create interactive 3D flip flashcards and multiple-choice practice tests with one click.
Where are student accounts and data stored? ▼
During development, data is stored in a clean server repository service in memory per student account. When you connect a database to the backend repository interface, data will persist permanently.
Can I sync study sessions with Google Calendar? ▼
Yes! The study assistant includes a one-click Google Calendar integration that creates pre-filled revision focus blocks with your study topics and summaries.
How are AI calls securely executed? ▼
All calls to Gemini models happen on the server via authenticated API proxy routes. Your GEMINI_API_KEY is never sent to the browser or bundled in frontend client assets.
