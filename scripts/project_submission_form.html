2. Project Summary (students fill in)
Problem addressed / target users:
Undergraduate and high-school students face intense cognitive overload when preparing for exams from voluminous lecture notes, textbooks, and PDF slides. Traditional static notes lack active recall mechanisms and structured conceptual clarity. CogniStudy AI addresses this by providing an intelligent study workbench that condenses complex academic text into structured summaries, interactive recall flashcard decks, auto-generated quizzes, and hierarchical concept mind maps with conversational AI tutor guidance.
Main features / user workflows (at least three):
1. Multi-Input AI Notes Summarizer: Students enter text or upload lecture PDFs with granular controls for length (short, medium, comprehensive), difficulty (beginner, advanced), and output format (detailed, bulleted, cheatsheet) powered by Gemini 3.8 Flash.
2. Interactive Active-Recall Revision Suite: Automatically extracts high-yield concepts into 3D interactive flashcards with flip/mastery tracking, 5-question multiple-choice quizzes with explanations, and visual hierarchical mind maps.
3. Persistent Student Workspace & AI Study Tutor: Secure authentication with session management, personal study library with search/favorites/CRUD persistence in Supabase PostgreSQL, and an embedded conversational AI Study Tutor with study note context awareness.
3. Technology & Implementation Checklist
Layer / item Technology / evidence (fill in)
Front end (framework, UI, validation) HTML5, Modern CSS3 (Glassmorphism dark design system, Flexbox/Grid), Modular Vanilla ES6+ JS, Client-side Regex & form constraints, Google Identity Services (GSI SDK).
Back end (language, framework, API) TypeScript, Node.js, Express.js REST API, Google @google/genai SDK (Gemini 3.8 Flash), Express Rate Limiter, Helmet-style security headers middleware.
Database (DBMS, tables / collections) Supabase (PostgreSQL) with SQLite fallback. 5 Structured Tables: students, sessions, study_items, activities, notifications with RLS & foreign keys.
Authentication / authorization Bearer Token session-based authorization (7-day TTL), cryptographic password hashing using crypto.scrypt with random salt, and Google OAuth 2.0 credential verification.
Testing / deployment tools Automated Node test runner (tsx --test, 11/11 tests pass), TypeScript strict linting (tsc --noEmit), Vite bundler, Git/GitHub, Vercel (Frontend), Render (Backend).
